## What's inside the deck (inspected 2026-11-01)
- **Format:** current Anki format (`collection.anki21b`, zstd-compressed SQLite), with a zstd media map.
- **4,823 notes → 9,646 cards** (each note gives Arabic→English and English→Arabic).

## Caveats
- The Gaza pronunciation differs in places from the Galilee, Triangle, and Jerusalem speech heard in Israel (e.g. ق). See the fact-check.
- One reported translation error (an Amazon review). Treat it as generally reliable, not perfect.
- The levels are Lingualism's own suggestions, not an official CEFR list.
