## Checked and found sound
- **`api/services.ts`:** answers three booleans and nothing else, only to a token Supabase accepts; refuses a missing or unknown token before any other work; `Cache-Control: private` with `Vary: Authorization`. Its unit tests look for every key prefix and provider name in the body and headers.
- **`api/partner.ts`:** the characters' sheets now come from our own `content/` on the server (`includeFiles`), looked up by id or number from a `Map`, so the browser can't hand the model a prompt of its own. The body limit went down (12 kB to 8 kB). A missing content file answers `failed`, not a crash. `content/` holds only our own text (ADR 0011).
- **`harden_rewards`:** trials and ranks count only in order; `record_review` and `record_result` became `security definer`, write only `auth.uid()`'s rows, and no player can call them directly; review cards and logs are capped at 2 kB each; a time-zone change can't move the day backward. Every function keeps `search_path = ''`.
- **The regulars' and rank-gear migrations:** data only.
- **`keep-alive.yml`:** `permissions: {}`; the secrets are read only in the one step that uses them; `psql`'s errors, which can name the host and user, stay out of the log; one project failing doesn't hide the other.
- **`ci.yml`:** only the time limit changed.
- **`vercel.json`:** the strict CSP is unchanged; `X-Robots-Tag: noindex, nofollow` added. The new painted scenes use classes, not inline styles, and `e2e/headers.spec.ts` passes.
- **The client:** no `dangerouslySetInnerHTML` outside the painters' own SVG (`HallBackdrop` turns it into an image); the compass's links are built from our content's door names; the first page's words are content checked by zod; nothing new is kept in the browser except whether the first page was closed.

## The walk: the first ten steps of each guild, as a new player on a phone
Each step's saved progress was built by the road tests' own `finish()`, then the square was opened and its compass line followed.

- **Signal Tower:** every line opened the screen it named (Hear K and M → the first lesson; "Key your first letters on the brass key" → the straight key; "Name each letter before its lamp fades" → Instant Recognition; "Face the Gatekeeper" → the trial). No doubt, apart from finding 1.
- **Caravanserai:** the same: the scribe's table, the coffee corner, the slate, the fountain, the storyteller, each with the screen's own title matching the line. One doubt found: finding 1 (the fountain's line was cut). Findings 3 and 4 are the only other places a player could stall, and neither can happen on the live site as configured.
- **Not walked here:** sound, the microphone and a real phone's touch. They are on Adam's release checklist (task 1.12).
