## 2. Your call: turning the check on
**Until you add the key, the button only says "The check isn't set up yet", and nothing is sent anywhere.** Adding the key is what turns it on, so here is what that means first. I checked all of it on 2026-11-06.

- **Cost:** none.
  - Groq's free tier is enough: 100 checks of a few seconds each is far below the free 2,000 requests and 28,800 audio-seconds a day. Those are the limits Groq's response headers showed on 2026-11-02. Groq's docs now list similar numbers, but under its Developer plan, so the free numbers aren't published anywhere.
  - Groq bills at least 10 seconds per request. That only matters on a paid plan.
  - Vercel Hobby includes 1,000,000 function calls a month. It's for personal, non-commercial use only, which fits Waymark.
- **Data sharing:** each press sends that one recording of your voice to Groq, in the US.
  - By default Groq doesn't keep it. It may keep logs for up to 30 days, only for reliability or abuse cases.
  - **I recommend turning on Zero Data Retention:** console.groq.com → Settings → Data Controls. Then nothing is logged at all.
  - Groq's data page doesn't say whether it trains on audio. Third-party summaries say it doesn't; I couldn't confirm that on Groq's own pages.
- **Lock-in:** small. The model and its settings sit in one file, `api/understood.ts`. Moving to another speech service means changing that file (ADR 0014; E15's AI adapter will take it over).

**If you're happy with that:** in Vercel → the `waymark` project → Settings → Environment Variables, add `GROQ_API_KEY`.
- Tick **Preview** (the dev site) and, when you want it live, **Production**.
- Use a key from console.groq.com. Separate keys for dev and live are best.
- Then redeploy: the next push or merge does it. **Never paste the key in chat.**
