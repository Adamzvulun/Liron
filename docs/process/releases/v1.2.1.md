- **Status:** ready for Adam to merge. It is the text of the release PR (`release/v1.2.1` → `main`).

## What a player gets

- **The square opens on an iPhone.** Signing in on Adam's iPhone crashed Safari ("A problem repeatedly occurred on …") before the square was drawn. The Signal Tower, opened directly, worked.

## What was wrong

To make the hover lift smooth with a mouse (#137), each of the five places in the square was its own layer from the start, and each layer was the whole 1920 × 1080 painting. The gold glows and the plaques' light added more. At an iPhone's 3× screen that is several layers of tens of megabytes each, more memory than Safari gives a page, so it ended the page. A touch screen can't hover, so on touch screens (`hover: none`) none of those layers are made now. With a mouse, nothing changes.

Claude couldn't open Safari to see the crash itself (the cloud session has only Chromium). The cause is inferred: the crash came as the square opened, and a painted page without those layers (the Signal Tower) worked on the same phone. A browser test now checks that a phone gets no layer half the stage or bigger.
