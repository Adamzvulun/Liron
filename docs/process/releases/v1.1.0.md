# Waymark 1.1.0 — Open to Friends

- **Status:** draft, written 2026-11-18. It becomes the text of the release PR (`release/v1.1.0` → `main`). The date goes in when Adam merges.
- **What this release is:** the step between playing alone and playing with friends ([VERSIONS](../VERSIONS.md#next-v110--open-to-friends)). Everything a friend needs is already in 1.0.0; this release lets a friend learn Arabic too, and makes the game say plainly what a site or an account can't do.

## What a player gets

- **Every friend learns from the deck** ([ADR 0050](../../decisions/0050-friends-learn-from-the-deck.md)). An account made for a friend reads the Caravanserai's lessons, recordings and words the moment it exists, with no step from Adam. Nobody signed out, and no anonymous session, can read them.
- **The game never points at a station that can't answer.** The compass in the square and in both halls now knows whether Sit and talk is switched on for this site. Without it, the Caravanserai's road says "Nobody is at the table on this site yet." and goes on with the next step it can offer.
- **An account without the deck is told so, not left guessing.** If a licence is ever taken away by hand, the Caravanserai keeps the whole road and its count, says "This account can't read the deck yet: ask whoever invited you.", and every door that reads the deck says the same instead of "haven't been loaded". The compass leads with the Signal Tower meanwhile.

## For Adam

- **One migration:** `20270107000000_every_account_reads_the_deck.sql`. On `waymark-prod` it adds every existing account to `content_licensees` and makes each new one a licensee as it's made. The DB migrate run on `main` applies it.
- **Your first friend** is now a short list: [FRIENDS.md](../FRIENDS.md#your-first-friend-in-order-task-37).

## Under it

- `core/road/facts.ts`: the platform asks once a page whether this account is a licensee (the database's own `is_content_licensee()`) and whether Sit and talk is set up (`/api/services`), and hands both to the compass and to every hall. A failed answer falls back to the common case, never to a closed door.
- The road's waits gain a reason, `deck`. A road whose next steps all wait shows one line that says why (`why: 'closed'`), and the square's compass lets a guild with a real step lead, for a new player too.
- Tests: the database (a new account reads deck rows; a deleted licence stays deleted; the backfill; nobody signed in can add a licence), the road (an account without the deck keeps its whole road and never gets a deck door), the compass, and a browser test that follows the compass as such an account (`tests/e2e/no-deck.spec.ts`).
- The v1 review's two lows are closed ([review](../reviews/2026-11-17-v1-review.md)).
