# Waymark 1.2.3 — The square as pictures on a touch screen

- **Status:** released 2026-11-21, merged by Claude once its checks passed (Adam's standing word). It is the text of the release PR (`release/v1.2.3` → `main`).
- **What this release is:** a fix release (X.Y.Z, [VERSIONS](../VERSIONS.md#how-to-read-a-version-number)), the third step on the iPhone crash (v1.2.1, v1.2.2).

## What a player gets

- **The square stays open on an iPhone,** looking as it did. After v1.2.2 Safari still reloaded the page about a second after the square appeared.

## What was wrong

The square is painted live as SVG, with about 100 filtered shapes: blurred shadows, plaster and grain textures, a depth-of-field blur. Together their filter regions cover about seven screens, and Safari keeps a full-size buffer for each at the screen's resolution. The Signal Tower, which opens fine on the same phone, has 15, covering under three screens. v1.2.1 and v1.2.2 removed the layers; the filters were the rest.

On a touch screen the square is now drawn as pictures: the background, each place, each plot and the front, each an SVG image. An image is filtered once into one bitmap. Under each place lie its shapes again, unseen and without filters, so a tap opens the building only where the building is. The page went from about 6,000 elements to under 1,800. With a mouse, nothing changes: the live painting moves and glows on hover.

Claude can't run Safari in the cloud session, so this is again inferred, from the counts above and the Signal Tower working. A phone test checks that no filtered shape is left on the page, that every picture loads, and that a tap on the tower opens it.
