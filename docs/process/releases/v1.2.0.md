# Waymark 1.2.0 — Invite links

- **Status:** ready for Adam to merge. It is the text of the release PR (`release/v1.2.0` → `main`). Claude prepared it overnight on 2026-11-20 because the feature is only useful on the live site: friends can't open the dev site's links.
- **What this release is:** a planned release inside the friends chapter (X.Y, [VERSIONS](../VERSIONS.md#how-to-read-a-version-number)): one feature, useful on its own.

## What a player gets

- **Invite a friend with a link.** Settings → **Invite a friend** → **Create invite link**, then **Share** (WhatsApp, Messages…) or **Copy link**. Only the project's first account (Adam's) can make links.
- **The friend makes their own account.** The link opens "Create your account": "Adam invited you to Waymark.", then Email, Password, Confirm password, **Create account**. They're signed in at once, and already Adam's friend in the Fellowship.
- **A preview card** under the link in chat apps: the city gate at dusk, WAYMARK, "Master real skills, one trial at a time".
- A link works once, for 7 days. An expired or used one says so. An email that already has an account is offered Sign in.
- Every password box refuses a password over 72 characters, which Supabase couldn't keep whole, instead of failing later.

## Under it
