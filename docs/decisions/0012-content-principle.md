# 0012 — Content principle: based on existing knowledge, tailored by us

- **Status:** Accepted
- **Date:** 2026-11-01
- **Clarifies:** the vision constraint "use existing sources; don't author source material", and ADR 0008

## Context
Earlier docs read Adam's "use existing sources" as "never create our own content". Adam clarified: **the learning is *based on* existing knowledge and courses, but we can create and tailor material.** He also decided **no more purchases**.

## Decision
1. **Base, then tailor.** Every lesson has a known basis: an established method, a reputable course's structure, or a source we own. On top of that we freely **create and tailor**: lessons, drills, explanations, examples, ordering, the Hebrew bridge, and games.
2. **The script is taught inside Waymark** (option b). The alphabet itself is public knowledge. The Madrasa "הכתב הערבי" course is used as a **structure and ordering reference**. Its videos are not copied.
3. **Grammar is taught inside Waymark** too. It's built from:
   - the Madrasa "ערבית מדוברת: מתחילים" course structure (reference);
   - free references (Zaytuna, Learn Levantine);
   - the example sentences in our Lingualism deck, so grammar is shown in real sentences we already have audio for.
4. **No more buying.** The Lingualism deck ($25, bought 2026-11-01) is the only paid source. Everything else must be free, or created by us.
5. **Fact discipline still applies** (CLAUDE.md): anything we create about the language (rules, pronunciation, cultural notes) is checked against a reputable source before it ships.

## Consequences
- The Hebrew-bridge extras in ADR 0002 (shared-root badges, binyanim ↔ verb-form notes) are clearly in scope. They're our own tailored content.
- Created content needs review. Since no native speaker is available, Claude cross-checks against the deck, Maknuune, and the free references, and flags anything uncertain.
- The Lingualism *Palestinian Arabic Verbs* book is **not** bought.
